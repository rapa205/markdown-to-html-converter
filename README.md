# 📝 Simple Markdown to HTML Converter

A lightweight, local, no-nonsense web tool that instantly converts Markdown text into clean HTML code and a live preview.

## ✨ Features
- **Instant Conversion:** Turns basic markdown headers, bold, and italic text into HTML tags on the fly.
- **Client-Side:** Runs completely in your browser with zero bloat or external dependencies.
- **Live Preview:** See both the raw generated HTML code and the rendered visual preview instantly.

## 🚀 How to Run Locally
1. Clone or download this repository to your computer.
2. Open `index.html` in any web browser (Chrome, Firefox, Edge, etc.).
3. Paste your markdown and hit convert!

## 🛠️ Built With
- HTML5 / CSS3
- Vanilla JavaScript
